# Sultan's Travel Advisory - Web Companion Portal 🌎✈️

Welcome to the static web companion for **Sultan's Travel Advisory & Global Student Study Helper**! 

This high-fidelity, single-page application (SPA) represents a matching web version of your Android application. Built entirely with **HTML5, Tailwind CSS, and Vanilla ES6 JavaScript**, it provides the exact same data, calculators, themes, search filters, and persistent bookmarking.

Because it contains zero server-side frameworks or heavy compile steps, you can run or host it completely for free in seconds!

---

## 🚀 How to Run the Website Locally
No terminal or node servers are required. Simply:
1. Extract the project **ZIP** downloaded from the Google AI Studio settings menu.
2. Open the `/web` folder.
3. Double-click `index.html` to open it in any web browser (Chrome, Edge, Safari, Firefox)!

---

## 🌐 How to Host & Publish Your Website for Free

You can deploy this static directory to the cloud in under 2 minutes:

### Option A: Netlify Drop (Fastest, drag-and-drop, no account required to test)
1. Open [Netlify Drop](https://app.netlify.com/drop).
2. Drag and drop the actual `/web` directory directly onto the browser screen.
3. Netlify will instantly provision an active SSL certificate and a custom, shareable link (e.g. `https://sultans-travel-advisory.netlify.app`)!

### Option B: GitHub Pages
1. Push your project code to a GitHub repository.
2. In the repository settings, go to the **Pages** tab.
3. Select your deployment source branch (usually `main`), change the folder to `/web` (or root if you moved the website files there), and click **Save**.
4. GitHub will host your website at `https://<your-username>.github.io/<repo-name>`.

### Option C: Vercel CLI / Vercel Dashboard
1. Go to [Vercel](https://vercel.com) and connect your GitHub profile.
2. Select your imported repository.
3. Set the **Root Directory** setting to `web` during configuration.
4. Click **Deploy**!

## 🎨 Implemented Web Features

- **Dynamic Theme Engine**: Live palette selection supporting *Cosmic Slate (Dark)*, *Samsung Aura (Galaxy Dark)*, *Emerald Horizon (Teal Light)*, and *Sunset Scholar (Amber Light)*, mirroring the exact Android themes!
- **Visa & Restriction Checker**: Robust interactive lookup system indicating general admission restrictions, border statuses, and specialized advisory warnings.
- **Academic Exchange Partner Database**: Complete indexing of target exchange campuses, fees, acceptance rates, and primary study majors.
- **Universal Strategy Manual**: Interactive travel checklist, containing specialized togglable summer and winter checklists.
- **Dynamic Expense Estimator**: Computing academic fees, local accommodations, and scholarship support to output clean sovereign balance sheets in real-time.
- **Live Flight deals tracker**: Interactive simulated pricing fluctuations and seat indicators that update automatically.
- **LocalStorage sync**: Ensuring bookmarked advisories and favorite universities remain locked safely inside your browser across page refreshes.
